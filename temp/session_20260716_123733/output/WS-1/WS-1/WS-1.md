## SYNOPSIS 2

Product rule: The derivative of product of two functions is given by the following

$$product \ rule \ \frac{d\big[f(x).g(x)\big]}{dx} = \left[\frac{d}{dx}\big(f(x)\big)\right].g(x) + \left[\frac{d}{dx}g(x)\right].f(x)$$

**Quotient Rule:** The derivative of quotient of two functions is given by the following quotient rule (whenever the denominator is non - zero)

$$\frac{d}{dx}\left(\frac{f(x)}{g(x)}\right) = \frac{g(x).\frac{d}{dx}(f(x)) - f(x).\frac{d}{dx}(g(x))}{\left(g(x)\right)^2}$$

The above two rules may be restated in the following functions which aids in recalling them easily

let 
$$f(x) = u$$
 and  $g(x) = v$ 

$$(uv)^{l} = u^{l}v + uv^{l}$$

This is referred to as Leibnitz rule for differentiating product of functions (or) the product rule.

Similarly the Quotient rule is  $\left(\frac{u}{v}\right)^l = \frac{v.u^l - u.v^l}{v^2}$ 

**Example-1:** The derivative of  $f(x) = x^n$  can be computed in the following way

Let 
$$f(x) = x^{n-1}.x$$

By product rule

$$\frac{d}{dx}f(x) = \left[\frac{d}{dx}\left(x^{n-1}\right)\right].x + \left[\frac{d}{dx}(x)\right].x^{n-1}$$

$$=(n-1).x^{n-2}.x+1.x^{n-1}$$

$$=(n-1).x^{n-2+1}+x^{n-1}$$

$$= x^{n-1}[n-1+1]$$

$$\frac{d}{dx}(x^n) = nx^{n-1}$$

**Example-2:** Find the derivative of  $f(x) = \frac{x+1}{x}$ 

$$\frac{d}{dx}(f(x)) = \frac{1}{x^2} \left[ x \left( \frac{d}{dx}(x+1) \right) - (x+1) \cdot \frac{d}{dx}(x) \right]$$

$$= \frac{1}{x^2} [x.(1) - (x+1)1] = -\frac{1}{x^2}$$

**Parametric Differentiation:** If x = f(t) and y = g(t) are the parametric equations of a curve then

(i) 
$$\frac{dy}{dx} = \frac{dy}{dt} \cdot \frac{dt}{dx} = \frac{g'(t)}{f'(t)}$$

(ii) 
$$\frac{d^{n}y}{dx^{n}} = \frac{d}{dt} \left( \frac{d^{n-1}y}{dx^{n-1}} \right) \left( \frac{dt}{dx} \right)$$

**Example:** If  $x = a \cos^3 \theta$ ,  $y = a \sin^3 \theta$  then  $\frac{dy}{dx}$ 

$$\frac{\mathrm{dx}}{\mathrm{d}\,\theta} = -3\mathrm{a}\cos^2\theta.\sin\theta$$

$$\frac{\mathrm{dy}}{\mathrm{d}\,\theta} = 3\mathrm{a}\sin^2\theta.\cos\theta$$

$$\frac{dy}{dx} = \frac{\frac{dy}{d\theta}}{\frac{dx}{d\theta}} = \frac{3a\sin^2\theta\cos\theta}{-3a\cos^2\theta\sin\theta} = -\tan\theta$$

**Derivative of Implicit Functions:** If f(x,y)=0, then differentiate each term w.r.t x reading y as a function of x and then collect the terms of  $\frac{dy}{dx}$  together on left hand side and remaining terms on right hand side and then find  $\frac{dy}{dx}$ .

Another Method: If f(x,y) = 0 then  $\frac{dy}{dx} = \frac{-\left(\frac{df}{dx}\right)}{\left(\frac{df}{dy}\right)} = \frac{\text{partial derivative of } f \text{ w.r to } x}{\text{partial derivative of } f \text{ w.r to } y}$ 

**Example:** If  $ax^2 + 2hxy + by^2 + 2gx + 2fy + c = 0$ 

$$a.(2x) + 2h\left(x.\frac{dy}{dx} + y.(1)\right) + 2by.\frac{dy}{dx} + 2g + 2f.\frac{dy}{dx} = 0$$

$$2ax + 2hx.\frac{dy}{dx} + 2hy + 2by.\frac{dy}{dx} + 2g + 2f.\frac{dy}{dx} = 0$$

$$\frac{dy}{dx}(2hx + 2by + 2f) = -(2ax + 2hy + 2g)$$

$$\frac{dy}{dx}(hx + by + f) = -(ax + hy + g)$$

$$\therefore \frac{\mathrm{dy}}{\mathrm{dx}} = \frac{-(\mathrm{ax} + \mathrm{hy} + \mathrm{g})}{\mathrm{hx} + \mathrm{by} + \mathrm{f}}$$
